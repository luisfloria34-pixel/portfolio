# Luis Floria Portfolio

Premium personal brand website featuring a scroll-driven cinematic Three.js intro, Framer Motion transitions, portfolio sections and Netlify-ready project inquiry form.

## Run locally

```bash
npm install
npm run dev
```

## Validate production

```bash
npm run lint
npm run build
npm run preview
```

## Deploy

Vite output lives in `dist/`. Deploy with:

- Build command: `npm run build`
- Publish directory: `dist`

Project inquiry form includes Netlify Forms detection markup.
